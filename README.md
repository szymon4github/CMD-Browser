# CMD-Browser

## Terminal Browser

This browser is for older or weaker (e.g. raspberry pi) devices that have problems with regular browsers.

## INSTALATION

To install CMD-Browser on your computer do this:

1. Run command `wget https://github.com/szymon4github/CMD-Browser/releases/download/1/installer.py`
2. Next run `python installer.py` or `python3 installer.py`
3. To run browser do command `python CMD-Browser.py`
